# 📄 ZIP to PDF Converter & PDF Topic Organizer

A privacy-focused, browser-based tool that converts PDF and JPG/PNG files inside a ZIP archive into a single PDF and helps users organize PDF pages topic-wise.

## 🌐 Live Website

https://dashagriva925.github.io/-zip-to-pdf-converter-and-pdf-correct-order-/

---

## ✨ Features

### 📦 ZIP to PDF Converter

- Upload a `.zip` file directly from your device.
- Supports PDF files inside ZIP archives.
- Supports JPG/JPEG/PNG images.
- Converts images into PDF pages.
- Combines supported files into one PDF.
- Works directly in the browser.
- No server upload required.
- Designed for large ZIP files.

### 📚 PDF Topic Organizer

Organize an existing PDF into a better topic-wise order.

#### 🤖 Automatic Mode

- Analyzes PDF page information.
- Detects possible chapter/topic numbering.
- Suggests a logical page order.
- Lets you review the proposed order.
- Creates a new organized PDF.

#### ✋ Manual Mode

- View PDF pages individually.
- Rearrange pages manually.
- Move pages up or down.
- Create a new PDF using your selected order.

---

## 🔒 Privacy

Privacy is a major focus of this project.

Your files are processed locally in your browser whenever possible.

**Files are not intentionally uploaded to a server by this website.**

This means your documents can remain on your device while you use the converter and organizer.
